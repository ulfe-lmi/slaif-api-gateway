Prices

Prices are in the rule's currency: per 1,000,000 tokens for input/cached/output/reasoning, plus a flat per-request price. Decimal strings are parsed without floats and must be non-negative; a blank dimension is unpriced.

Validity

Valid from/until are UTC ISO datetimes; blank "Valid until" means open-ended. Source URL records the pricing source for provenance. Metadata JSON is operator metadata about the pricing entry.

Audit

Notes are operator metadata; Reason is the required audit reason. Provider API key values are never entered here; provider configs reference environment variable names only.
