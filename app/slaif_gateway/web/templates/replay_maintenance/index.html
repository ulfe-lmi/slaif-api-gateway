What this manages

Retained Codex replay references are short-lived, same-key replay pointers with stored expiry times. Inspection is read-only and writes nothing. An extension only lengthens the expiry of eligible references to original creation time + the selected lifetime; it never shortens, recreates, or transfers a reference, and it never restores unusable material, grants replay access, or changes any other key state.
