Identity

Email is the account's unique sign-in identifier (lowercased; stored exactly once per account; at most 320 characters with a dot in the domain). A value that matches a known incoming authentication value is refused and never stored.

Display name is shown to other administrators (1 to 200 characters after trimming). A value that matches a known incoming authentication value is refused and never stored.

Password

Choose a strong, long, unique password (at least 12 characters recommended). The exact characters you enter are used: nothing is trimmed or normalized; nonempty, at most 128 characters. The password is never shown again, never stored in plain text, and never appears in the audit log, URLs, or page content — only its Argon2id hash is kept.

Re-enter the same password; the two entries must match exactly, character for character. Neither value is ever re-displayed after you leave this page.

Role

An ordinary admin manages keys, owners, routes, pricing, reports and the day-to-day console. A superadmin additionally manages administrator accounts and privileged recovery surfaces — creating one is a durable privilege escalation, so it requires the explicit acknowledgement below. First-admin and break-glass access remain on the offline CLI; nothing is elevated silently.
