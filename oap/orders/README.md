# OAP work orders

The strategic model owns this directory's work-order content. Before
activation it contains no executable order. After activation, the coding agent
executes only the unique `NNN-L-*.md` order selected by `../active` and never
edits an activated order.

One-time human-authorized exception (2026-11-14): the single exceptional
order `224-aa-*.md` (the objective-224 CI-repair round) is admissible; no
other two-letter-suffix identifier is valid.
