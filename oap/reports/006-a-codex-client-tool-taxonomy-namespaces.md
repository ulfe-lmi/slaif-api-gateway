## Changes made

- Added known Responses capability `codex_client_tools`, with conservative
  route default `false` and no template/calibration default injection.
- Required both well-formed key grants before shape validation and both route
  grants before Redis, pricing, quota, or provider work. Neither Codex
  capability nor ordinary function/custom-tool permission implies the other.
- Detected client declarations from request input shape only, never headers,
  user agents, endpoint permission, or model names.
- Accepted at most one exact `type=additional_tools`, `role=developer` item
  with two unique namespace containers and no ID, content, metadata, results,
  provider state, or unknown fields.
- Pinned the canonical taxonomy and order to `functions` containing `exec`
  custom grammar, `wait` function, and `request_user_input` function, followed
  by `collaboration` containing `followup_task`, `interrupt_agent`,
  `list_agents`, `send_message`, `spawn_agent`, and `wait_agent`, all functions.
- Reused bounded local function/custom validation and added aggregate property,
  schema-depth, schema/format/description, namespace/tool-count, and complete
  declaration-size limits. `exec` requires a bounded `lark` or `regex` grammar.
- Recursively denied provider authority and hosted/MCP/connector/server/auth/
  header/secret/approval/shell/apply-patch/computer/web/file/code-interpreter/
  image/tool-search shapes without echoing private input.
- Allowed only string `tool_choice` values `none`, `auto`, or `required` for
  namespace declarations; named/object choices and ambiguous top-level tools
  fail closed.
- Counted the canonical declaration, descriptions, function schemas, grammar,
  and choice conservatively as model request input. Safe evidence contains
  approved categories plus aggregate byte/token counts, not private values.
- Preserved the existing canonical normalized request/builder unchanged after
  verifying that it already deep-copies all policy-approved input items.
- Preserved the existing text-only streaming event allowlist and all hosted,
  stateful, tool-result, gateway-execution, and remote-authority exclusions.
- Allowed key templates to preserve `codex_client_tools` only when explicitly
  selected in a reviewed snapshot; neither Codex capability is generated by
  defaults or calibration discovery.
