# OAP execution reports

The coding agent publishes exactly one immutable `NNN-L-*.md` report for each
active execution round. The strategic model reads and independently verifies
reports but never edits them.

One-time human-authorized exception (2026-11-14): the single exceptional
report `224-aa-*.md` (the objective-224 CI-repair round) is admissible; no
other two-letter-suffix identifier is valid.
